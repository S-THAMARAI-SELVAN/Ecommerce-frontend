# 🚀 Features

### Frontend
- **State Management**: Redux Toolkit for consistent cart, auth, and wishlist flows.
- **Client Routing**: Single Page Application structure powered by React Router.
- **Responsive UI**: Sleek, modern, and adaptive interface for mobile, tablet, and desktop views.

### Backend
- **Robust Authentication**: JWT (JSON Web Tokens) with automated access/refresh tokens.
- **Cold-Start Protection**: Custom built-in **Self-Ping Keep-Alive service** to prevent container idling/sleep cycles on cloud environments.
- **RESTful API**: Structured endpoints for user accounts, products, cart handling, and order checkout.
- **Resilient Fallback Mode**: Embedded database recovery fallback that gracefully shifts to mock in-memory storage if MongoDB becomes temporarily unreachable.

# 🛠️ Tech Stack

## Frontend
- **React.js** (v18)
- **Vite** (Next-generation frontend tooling)
- **Redux Toolkit** (State Management)
- **React Router DOM** (Navigation)
- **Vanilla CSS** (Custom theme configurations)
- **Axios** (API Client with dynamic endpoint routing)
- **Lucide React** (Modern Icons)

## Backend
- **Node.js**
- **Express.js** (REST API framework)
- **Mongoose** (Object Modeling for MongoDB)
- **Bcrypt.js** (Password hashing security)

## Database & Cloud Services
- **MongoDB Atlas** (Cloud Database)
- **Vercel** (Frontend Deployment)
- **Render** (Backend Hosting)
- **UptimeRobot** (Service Uptime Monitor & ping checks)
